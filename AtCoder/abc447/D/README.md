## 問題文
A,B,Cの3種類の文字のみからなる文字列Sが与えられます。

操作を以下のように定義します。

1 \le i \lt j \lt k \le |S|かつS_i =A,S_j =B,S_k =Cを満たす(i, j, k)の組を選び、Sのi, j, k文字目を取り除く。

残った文字を元の順序を保ったまま左に詰める。

文字列Sに対して最大で何回操作を行うことができるかを求めてください。
