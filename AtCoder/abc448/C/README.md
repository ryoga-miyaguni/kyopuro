## 問題文
1からNの番号がついたN個のボールが袋に入っています。

ボールiには整数A_iが書かれています。

Q個のクエリを処理してください。

クエリでは長さKの数列B_1, B_2, \dots, B_{K}が与えられるので以下の一連の操作を行ってください。

ここで、B_iは全て1以上N以下で、かつ相異なります。

まず、ボールB_1, ボールB_2,\dots, ボールB_Kを全て袋から取り出す。

そして、現在の袋に入っているボールに書かれた整数の最小値を出力する。

(この時、袋は空でないことが制約から保証されている。

)その後、取り出したK個のボールを全て袋に戻す。
