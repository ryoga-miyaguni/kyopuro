# F - abc448_f

- **URL:** https://atcoder.jp/contests/abc448/tasks/abc448_f
- **難易度:** F

## 問題文
2次元平面上に1からNの番号がついたNカ所の地点があります。

地点iは座標(X_i, Y_i)にあります。

あなたは地点1を出発して全ての地点をちょうど1回ずつ巡回して再び地点1に戻ることにしました。

ここで、地点iから地点jへ移動するには\vert X_i - X_j \vert + \vert Y_i - Y_j \vert秒かかります。

地点1を出発してから10^{10}秒以内に全ての地点を巡回して再び地点1に戻ることができる経路を出力してください。

なお、制約下においてこの条件を満たす経路が少なくとも1つ存在することが保証されます。
