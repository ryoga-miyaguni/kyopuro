## 考察・学んだこと
- for文の中で、P += i と配列の中に数字を入れようとしていた。しかし、+= を使う場合は、右側がイテラブル（リストやrangeなどの中身が並んでいるもの出ないといけないからエラーが出ていた。
- print(range(5)) → range(0, 5)　だから中身を実体化して使わないといけない。リストに変換する方法 → list(range(5))。展開する方法 → print(*range(5))。
