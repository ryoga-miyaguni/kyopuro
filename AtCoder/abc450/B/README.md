# B - abc450_b

- **URL:** https://atcoder.jp/contests/abc450/tasks/abc450_b
- **難易度:** B

## 問題文
N個の駅1,2,\dots,Nがあり、これらはこの順に西から東に一直線上に並んでいます。

AtCoder 鉄道の電車はこれらN個の駅を通り、西から東に走っています。

1 \leq i \lt j \leq Nを満たす任意の2整数i,jについて、駅iから電車に乗って駅jで降りるのにコストがC_{i,j}かかります。

以下のような3つの整数a,b,cが存在するかを判定してください。

1 \leq a \lt b \lt c \leq N駅aから電車に乗って駅cで降りるときにかかるコストよりも、駅aから電車に乗って駅bで降り、再度、駅bから電車に乗って駅cで降りるときにかかるコストの総和の方が小さい。

## 考察・学んだこと
- もう一度やった方がいい。あとで扱いやすいように　N＋1　の大きさで配列を作っているところとか、全条件を試す形で実装しているところとか。

- cost = [[0] * (N + 1) for _ in range(N + 1)]　
- [0] * (N + 1) → 「0 という要素が1つ入ったリスト」を N + 1 回繰り返して、1つのリストにする。
- for _ in range(N + 1) → リスト内包表記（1行分のリストを作る作業を、N + 1 回繰り返す）
