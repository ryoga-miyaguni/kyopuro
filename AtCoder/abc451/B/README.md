## 問題文
高橋君の勤めている会社にはN人の社員がおり、各社員には1,2,\dots,Nの社員番号が割り当てられています。


社内にはM個の部門があり、部門1,2,\dots,Mと呼ばれています。

社員番号iの社員は、今期は部門A_iに所属しており、来期は部門B_iに所属します。

部門1,2,\dots,Mそれぞれに対して、来期の所属人数から今期の所属人数を引いた値を求めてください。

## 考察・学んだこと
- elif ではなく、if を使わないと2年続けて同じ部署の人が正しくカウントできなくなる
- range(m) だと、０から m - 1になってしまうからずれてしまう
- バケット法というやり方でO(N * M) → O(N + M)にして計算量を減らすことができる
```python
def main():
    # 1. N(社員数), M(部門数) を取得
    N, M = i_map()
    
    # 2. A_i, B_i のリストを取得（各行に2要素あるので row_list）
    # S[i][0] が今期の部門 A_i, S[i][1] が来期の部門 B_i
    S = i_row_list(N)

    # 3. 各部門の「人数の変化量」を記録するリストを用意 (1番〜M番まで使うので M+1 サイズ)
    # diff[j] = (部門 j の来期の人数) - (部門 j の今期の人数)
    diff = [0] * (M + 1)

    # 4. 社員ごとに所属部門の変化をカウント
    for i in range(N):
        now_dept = S[i][0]  # 今期
        next_dept = S[i][1] # 来期
        
        # 今期所属している部門からは -1人
        diff[now_dept] -= 1
        # 来期所属する部門には +1人
        diff[next_dept] += 1

    # 5. 部門 1 から M まで順番に出力
    for j in range(1, M + 1):
        print(diff[j])

if __name__ == '__main__':
    main()
```
