## 問題文
高橋くんは、庭にある木の本数を管理しています。

はじめ、庭に木は1本もありません。

Q個のクエリが順に与えられます。

クエリは次の2種類のいずれかです。

各クエリを処理した直後に庭にある木の本数を出力してください。

1 h: 庭に高さhの木を新たに1本追加する。

2 h: いま庭にある木のうち、高さがh以下の木をすべて削除する。
