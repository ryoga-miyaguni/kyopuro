## 問題文
以下の条件を満たす正整数を良い整数とします。

条件：一つ以上の2の冪（1,2,4,8,16,\dots）を（重複と並び替えを許して）選んで文字列として結合し、それを整数として解釈することで得られる。

良い整数のうちN番目に小さいものを求めてください。


ただしN番目に小さい良い整数は10^9以下であることが保証されます。
