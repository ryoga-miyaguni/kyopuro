## 問題文
英小文字からなる文字列S,Tが与えられます。

Sの空でない部分文字列sのうち、Tを（連続するとは限らない）部分列として含まないものの個数を求めてください。

ここで、Sの2つの部分文字列は、取り出した箇所が異なれば文字列として等しくても区別するものとします。

部分文字列とは文字列Xの部分文字列とは、Xの先頭から0文字以上、末尾から0文字以上を削除して得られる文字列のことを指します。

部分列とは文字列Xの部分列とは，Xの要素を0個以上選んで削除し，残った要素を元の順序を保って並べた文字列のことを指します．
