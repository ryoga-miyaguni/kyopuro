## 考察・学んだこと
- 最初は下のように書いていた。
```python
    a = i_map()
    b = i_map()
    c = i_map()
```
    - 1. 比較の失敗
        a = i_map() で受け取った a の中身は「数値」ではなく、「mapオブジェクト（計算手順）」という特殊な入れ物です。
        たとえ中身が同じ 2 でも、入れ物（map）どうしを == で比べると必ず False になります。

    - 2. 行の読み飛ばし
        テンプレートの i_map() は実行するたびに 1行まるごと 読み込みます。

        a = i_map() → 1行目を読み込む

        b = i_map() → 2行目を読み込む

        c = i_map() → 3行目を読み込む
        もし入力データが1行（1 2 2）なら、b と c は読み込むデータがなくてエラーになります。
